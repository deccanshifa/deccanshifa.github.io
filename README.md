# Deccan Shifa Diagnostic Centre Website — v1.0

Tagline: **Precision Diagnosis for Optimal Treatment.**

## Upload structure

Put `index.html` in the repository root.

Put:
- `style.css` -> `assets/css/style.css`
- `responsive.css` -> `assets/css/responsive.css`
- `script.js` -> `assets/js/script.js`

The `images`, `icons`, and `fonts` folders are prepared for later assets.

## Important
The homepage intentionally contains placeholders for phone, WhatsApp, address, working hours, doctor details, package details, logo and photographs. Replace them with verified information before publishing.

## External libraries
Bootstrap 5.3.3, Font Awesome 6, AOS 2.3.4 and Google Fonts are loaded from CDNs.
